# 文学的欢乐生日派对

这是一个纯静态生日网页，不需要安装项目依赖。

## 预览

在此文件夹中运行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000>。

“点我庆祝”可直接使用。语音识别需要浏览器支持 Web Speech API；Chrome 或 Edge 的兼容性较好。正式部署时请使用 HTTPS，浏览器才会允许正常请求麦克风权限。

## 语音互动

- 请在手机横屏打开；竖屏时网页会提示旋转设备。
- 启动“声波”后，说“文学，生日快乐！”：人物进入赛博鬼畜舞蹈、彩带爆发，并播放约 20 秒的合成生日旋律。
- 启动“声波”后，说其他内容：人物会按每句话切换不同动作照，同时从镭射指挥、迪斯科、BOSS 战、蛋糕引擎、离谱警报、行星公转、故障模式和火箭发射中触发一种音效与舞台反应；连续反应不会重复。
- 声波开启时会显示实时音量波形、麦克风状态和正在识别的语句；声音越明显，霓虹波形与舞台光晕越强。
- 生日歌期间会轮换人物动作照，并启动一套赛博机甲四肢的鬼畜舞蹈。
- 再次点击“停止声波”即可关闭持续聆听。不支持或未授权麦克风时，使用“强制开趴”即可启动生日演出。
- 点击“文学竞猜”可进入 8 题无厘头有奖竞猜；每题四个离谱答案，答对和答错都有赛博奖品。
- 点击“声控迷宫”可进入 10×6 的真实单关迷宫副本。点击“启动声控闯关”后，游戏会先用约 2 秒校准自然说话音高：音量控制向右推进速度，高音让文学上行，低音让文学下行，安静时停住。说“文学生日快乐”可触发一次向左战术后退，方便重新选路。墙体有真实碰撞，必须绕路；小怪兽和地雷会扣体力并震退文学，回血蛋糕、赛博电池与加分星星位于可选支路。抵达右上角礼物终点即可解锁生日礼物。

页面不保存、不上传任何语音。舞台人物素材位于 `assets/portraits/`，原始照片没有被修改。
