# 文学的欢乐生日派对

这是一个纯静态生日网页，不需要安装项目依赖。

## 预览

在此文件夹中运行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000>。

“点我庆祝”可直接使用。语音识别需要浏览器支持 Web Speech API；Chrome 或 Edge 的兼容性较好。正式部署时请使用 HTTPS，浏览器才会允许正常请求麦克风权限。

## 语音互动

- 请在手机横屏打开；竖屏时网页会提示旋转设备。
- 启动“声波”后，说“文学，生日快乐！”：人物进入赛博鬼畜舞蹈、彩带爆发，并播放约 20 秒的合成生日旋律。
- 启动“声波”后，说其他内容：人物会按每句话变换霓虹故障、镜像、酸性或虚空形态，同时播放合成喝彩声。
- 再次点击“停止声波”即可关闭持续聆听。不支持或未授权麦克风时，使用“强制开趴”即可启动生日演出。

页面不保存、不上传任何语音。人物素材位于 `assets/wenxue.png`，原始照片没有被修改。
